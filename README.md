# Freight Rate Prediction Challenge

Predict `posted_rate` for 12,000 loads (Nov-Dec 2025) from 48,000 labelled loads (Jan-Oct 2025).

Result in brief

|                   |                                                                                                                                 |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| Final model       | Gradient Boosting Regressor (scikit-learn), tuned with`RandomizedSearchCV`                                                    |
| Validation design | Time-based: train Jan-Aug, hold-out Sep-Oct                                                                                     |
| Hold-out score    | R² 0.825, MAE $131, MSE 408,034                                                                                                |
| Outputs           | `validation_predictions.csv` (12,000 rows), `december_predictions.csv` (31 rows), `scorer_results/candidate_december.png` |

The full write-up (data issues, split approach, December chart) is in `Freight_Rate_Report.docx`.

## How to run

1. Python 3.10+ is recommended.
2. Install dependencies:

```bash
python -m pip install -r requirements.txt
```

3. Open `notebooks/solution.ipynb` and choose **Run All**. It will:
   - train and compare Linear Regression, Random Forest, Gradient Boosting and Linear SVR,
   - tune the three strongest models and select the best on the hold-out,
   - save `artifacts.joblib` (model, equipment encoder, imputation statistics),
   - write `validation_predictions.csv` and `december_predictions.csv` to the repository root.
4. Validate both files and generate the December chart (run from the repository root):

```bash
python score.py --predictions validation_predictions.csv --december-predictions december_predictions.csv
```

The scorer checks the file formats and creates `scorer_results/candidate_december.png`.

## Approach

- **Cleaning:**
  - negative `weight` -> absolute value;
  - missing `weight` -> median by equipment
  - missing `market_index` -> median of the same day (interpolated) in training, training global median for validation / December
  - whitespace stripped
  - dates parsed.
- **Features:** distance, weight, market_index, quote_signal, equipment (label-encoded), month, day of week, pickup/delivery lat/lon, lat/lon differences, distance x market_index.
- **Validation:** strictly time-based split (Jan-Aug train, Sep-Oct test) because the real validation set lies after the training period. A random split would leak future information.
- **Model selection:**
  - hyperparameter search on the training period only
  - tuned models compared on the hold-out.
- **December chart:** the December file only has six columns, so coordinates come from the training data and `market_index` / `quote_signal` are set to their training medians with small random noise (seed 42).

## Reproducibility

- Random seed 42 for the models, the hyperparameter search and the December inputs.
- Imputation statistics and the encoder are fitted on training data only and reused for validation and December.
- December `market_index` / `quote_signal` are assumptions, so the December chart is nearly flat by construction and is not a seasonal forecas

## What to do

1. Train and validate your model using `data/train_test.csv`.
2. Predict every load in `data/validation.csv`. Each load has a unique `load_id`.
3. Fill the matching `predicted_rate` values in `data/validation_predictions_template.csv` and save it as `validation_predictions.csv`.
4. Predict every row in `data/december_chart_inputs.csv` by filling its `predicted_rate` column.
5. Install the scorer requirements and run:

```bash
python -m pip install -r requirements.txt
python score.py --predictions validation_predictions.csv --december-predictions december_predictions.csv
```

The scorer validates both files and creates `scorer_results/candidate_december.png`.
